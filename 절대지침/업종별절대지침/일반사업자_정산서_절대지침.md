# 🏢 일반사업자 정산서 절대지침

## 📋 지침 개요
- **지침명**: 일반사업자 공급받는자 절대지침
- **적용 업종**: 일반사업자 (소상공인, 중소기업, 대기업 등)
- **상태**: 준비중 (preparing)
- **목적**: 일반사업자 정산서에서 공급받는자 정보를 정확하게 추출

## 🎯 추출 규칙

### 1. 상호명 추출 키워드
```
회사명, 업체명, 사업체명, 상호, 기업명, 법인명
사업자명, 업소명, 사업장명, 기관명, 단체명
```

### 2. 추출 기준
- **최소 필드 수**: 4개 이상 필수
- **신뢰도 임계값**: 0.4 이상
- **우선순위 필드**: 사업자등록번호, 상호, 대표명, 사업장주소, 사업자이메일

### 3. 일반사업자 특성
- 배달대행사와 달리 더 정형화된 데이터 구조
- 법인명, 회사명 등이 주요 식별자
- 사업자등록번호가 더 정확하게 기재됨

## 📊 추출 성공률 목표
- **목표 성공률**: 85% 이상
- **높은 신뢰도**: 70% 이상
- **중간 신뢰도**: 40-70%
- **낮은 신뢰도**: 40% 미만

- [ ] 테스트 케이스 작성
- [ ] 성능 최적화

## 📝 참고사항
- 일반사업자는 배달대행사보다 더 엄격한 검증 기준 적용
- 법인명과 개인사업자명을 구분하여 처리
- 사업자등록번호 형식 검증 강화 필요

## 🚀 현재 상태
- **전기 연결**: ✅ 완료 (프런트엔드 → 백엔드 → ConversionEngine → RecipientExtractor)
- **추출 로직**: ✅ 완료 (업종별 키워드 및 검증 기준 적용)
- **테스트**: 🔄 진행중
