# 👤 유저 프로필 수정 지침

이 문서는 유저 프로필 수정 기능에 대한 보안 및 비즈니스 규칙을 정의합니다.

---

## 🔒 보안 규칙 (절대 준수)

### **사업자번호 수정 제한**
- **사업자번호는 절대 수정할 수 없습니다**
- **이유**: 사업자번호 변경 시 다른 유저의 변환 작업에 접근할 수 있는 보안 취약점 발생
- **위험성**: 
  - 다른 유저의 세금계산서 변환 결과 조회 가능
  - 개인정보 유출 위험
  - 시스템 무결성 훼손

### **수정 가능한 필드**
- ✅ **회사명** (company_name)
- ✅ **대표자명** (representative_name)  
- ✅ **전화번호** (phone)
- ✅ **이메일** (email)
- ✅ **사업장 주소** (address)
- ✅ **업태** (business_type)
- ✅ **종목** (business_category)

### **수정 불가능한 필드**
- ❌ **사업자등록번호** (business_number) - 보안상 절대 금지
- ❌ **사용자명** (username) - 시스템 식별자
- ❌ **비밀번호** (password) - 별도 비밀번호 변경 기능 사용

---

## 🛡️ 검증 규칙

### **입력 데이터 검증**
1. **업태**: 2자 이상, 한글/영문/숫자만 허용
2. **종목**: 3자 이상, 한글/영문/숫자만 허용
3. **전화번호**: 한국 전화번호 형식 검증
4. **이메일**: 표준 이메일 형식 검증
5. **주소**: 최대 200자 제한

### **중복 검증**
- **이메일**: 다른 유저와 중복되지 않아야 함
- **전화번호**: 다른 유저와 중복되지 않아야 함

---

## 📋 수정 프로세스

### **1단계: 권한 확인**
- 로그인된 유저만 수정 가능
- 본인 정보만 수정 가능

### **2단계: 데이터 검증**
- 클라이언트 사이드 검증
- 서버 사이드 검증
- 절대지침 준수 확인

### **3단계: 업데이트 실행**
- 트랜잭션으로 안전하게 처리
- 변경 이력 로그 기록
- 실시간 반영

### **4단계: 결과 확인**
- 성공/실패 메시지 표시
- 변경된 정보 즉시 반영

---

## 🔍 감사 로그

### **기록 항목**
- 수정 시도 시간
- 수정한 유저 ID
- 수정된 필드 목록
- 수정 전/후 값
- IP 주소
- 성공/실패 여부

### **로그 보관**
- 최소 1년간 보관
- 개인정보 보호법 준수
- 관리자만 접근 가능

---

## ⚠️ 주의사항

### **개발자 주의사항**
- 사업자번호 필드는 UI에서 완전히 숨김 처리
- 백엔드에서도 사업자번호 수정 요청 차단
- 모든 수정 API에서 사업자번호 필터링

### **사용자 안내**
- 사업자번호 변경이 필요한 경우 고객센터 문의
- 다른 필드는 언제든지 수정 가능
- 수정 후 즉시 반영됨

---

## 🎯 결론

**사업자번호 수정 제한은 시스템 보안의 핵심입니다.**

- ✅ 안전한 프로필 수정 기능 제공
- ❌ 보안 취약점 완전 차단
- 🔒 유저 데이터 무결성 보장
- 📊 모든 변경사항 추적 가능
