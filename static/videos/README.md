# VIP 팝업 시뮬레이션 영상

## 영상 파일 위치
- **MP4**: `data_cleaning_demo.mp4`
- **WebM**: `data_cleaning_demo.webm` (선택사항)

## 영상 시나리오 (7가지 컬럼 반영)

### 1. 사업자번호 정제 시뮬레이션 (0-2초)
- **시작**: `212-12-99909`
- **마우스 클릭**: 하이픈(-) 제거 애니메이션
- **결과**: `2121299909`

### 2. 공급가액 합계 정제 시뮬레이션 (2-4초)
- **시작**: `1,000,000₩`
- **마우스 호버**: 쉼표(,)와 원화(₩) 기호 제거 애니메이션
- **결과**: `1000000`

### 3. 세액 합계 정제 시뮬레이션 (4-6초)
- **시작**: `100,000₩`
- **마우스 호버**: 쉼표(,)와 원화(₩) 기호 제거 애니메이션
- **결과**: `100000`

## 영상 스타일 가이드
- **배경**: 단색 배경 (흰색 또는 회색)
- **포커스**: 엑셀 셀 부분만 클로즈업
- **마우스 커서**: 강조된 커서 움직임 (각 셀마다 순차적으로)
- **해상도**: 최소 480x200px
- **길이**: 6초 루프 (3개 시나리오 × 2초씩)
- **포맷**: MP4 (H.264), WebM (선택사항)

## 고급 정제 효과
- **사업자번호**: 하이픈(-) 제거 → 순수 숫자
- **공급가액**: 쉼표(,) + 원화(₩) 제거 → 순수 숫자
- **세액**: 쉼표(,) + 원화(₩) 제거 → 순수 숫자

## 현재 상태
영상 파일이 없을 경우 고급 CSS 애니메이션으로 대체 표시됩니다:
- 마우스 커서 움직임 시뮬레이션
- 순차적 정제 효과 애니메이션
- 마법 스파클 효과
