## 📍 TV 배치 상세

### 프레임 (베젤)
- **위치**: (0, 5.0, 15.2)
- **프레임 뒷면**: z = 15.0m (앞벽에 정확히 붙음)
- **계산식**: 
  - 프레임 position.z = -bezelThickness/2 = -0.1
  - 프레임 뒷면 = tvGroup.z + frame.z - bezelThickness/2
  - 15.2 - 0.1 - 0.1 = 15.0m ✓

### 스크린
- **위치**: (0, 5.0, 15.31)
- **프레임보다 앞**: position.z = bezelThickness/2 + 0.01 = 0.11
- **방향**: rotation.y = Math.PI (180도) - 사용자(-Z 방향)를 향함

### 플레이 버튼
- **위치**: (0, 약 2.0, 14.2)
- **TV 스크린 아래 중앙**
- **방향**: 사용자를 향함
