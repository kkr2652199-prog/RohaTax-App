## 🎯 변환 전체 흐름 (순서도)

### 1단계: 파일 업로드 검증
**코드 위치**: `core/file_parser.py` 라인 327-350
**핵심 로직**:
- 파일 형식 검증 (Excel, CSV)
- 파일 크기 제한 확인 (50MB)
- 임시 저장소에 파일 저장

### 2단계: 시트 검열 (Sheet Inspection)
**코드 위치**: `core/file_parser.py` 라인 484-900
**핵심 로직**:
```python
# 1순위: Fast-Path 시스템 (아빠 금액 선점)
priority_sheet = self._find_priority_sheet(workbook, self.required_keywords)
if priority_sheet:
    return priority_sheet  # 즉시 선택, 2순위 검열 중단

# 2순위: 점수제 시스템 (5가지 필수 컬럼 + 가중치)
sheet_score_pts = (
    (30 if has_business_number else 0) +  # 사업자등록번호
    (10 if has_representative else 0) +    # 대표자명
    (30 if has_address else 0) +           # 주소
    (20 if has_email else 0) +             # 이메일
    (10 if has_store_name else 0)          # 상호명
)

# 3순위: 총배달 금액 보너스 (최대 50점)
delivery_bonus = min(total_delivery_amount / 1000000, 50)
final_score = sheet_score_pts + delivery_bonus
```

### 3단계: 헤더 감지 (Header Detection)
**코드 위치**: `core/file_parser.py` 라인 163-170
**핵심 로직**:
- 데이터 밀도 기반 헤더 감지
- 텍스트 비율이 높을수록 헤더일 가능성 높음
- 헤더 점수 = 텍스트비율 × 2 + 숫자비율 × 0.5 + 빈칸비율 × 0.1

- 즉시 선택하여 2순위 프로세스 중단

**A5**: 동일 사업자번호 그룹화
- 실행 시점: 데이터 추출 후
