# 변환 시스템 테스트 자동화 가이드

## 개요
변환 시스템의 안정성을 보장하기 위한 테스트 자동화 가이드입니다. 향후 변환 로직 수정 시 반드시 이 가이드에 따라 테스트를 수행해야 합니다.

---

## 🚀 테스트 실행 방법

### 기본 테스트 실행
```bash
# 전체 테스트 실행 (4개 파일)
python tests/test_conversion_system_full.py

# 특정 모드로 테스트 실행
python tests/test_conversion_system_full.py --mode=current    # 5종 금지어
python tests/test_conversion_system_full.py --mode=improved   # 7종 금지어

# 특정 파일만 테스트
python tests/test_conversion_system_full.py --file=sample_invoice.xlsx

# 리포트만 재생성
python tests/test_conversion_system_full.py --report-only
```

### 간소화 테스트 실행 (한글 경로 문제 시)
```bash
# 간소화 버전 테스트
python test_conversion_simple.py
```

## 🔍 테스트 검증 항목

### 1. 시트 선택 검증
- **Fast-Path 시트 선택**: "발행용", "정산서" 등 우선 시트 선택 확인
- **데이터 밀도 기반 선택**: VAT 컬럼 최대값 기준 시트 선택 확인
- **choose_last 정책**: 동점 시 더 아래 시트 선택 확인

### 2. 7종 컬럼 매칭 검증
- **사업자등록번호**: 키워드 매칭 및 금지어 차단 확인
- **상호명**: 키워드 매칭 및 금지어 차단 확인
- **주소**: 키워드 매칭 및 금지어 차단 확인
- **대표자**: 키워드 매칭 및 금지어 차단 확인
- **이메일**: 키워드 매칭 및 금지어 차단 확인
- **공급가액**: 키워드 매칭 및 금지어 차단 확인 (신규)
- **부가세**: 키워드 매칭 및 금지어 차단 확인 (신규)

### 3. 금지어 시스템 검증
- **5종 기존 금지어**: 정상 작동 확인
- **공급가액 금지어**: "총금액", "합계금액" 등과 구분 확인
- **부가세 금지어**: "세금계산서", "VAT" 등과 구분 확인

### 4. 공급받는자 추출 검증
- **추출 성공률**: 100% 달성 확인
- **가족통합**: 동일 사업자번호 자동 통합 확인
- **VAT 0원 제외**: 전자세금계산서 발행 불가 건 제외 확인

### 5. 템플릿 기입 검증
- **기입 성공률**: 100% 달성 확인
- **기입 순서**: 공급자 → 공급받는자 → 금액 정보 순서 확인
- **데이터 정확성**: 추출된 데이터와 기입 데이터 일치 확인
