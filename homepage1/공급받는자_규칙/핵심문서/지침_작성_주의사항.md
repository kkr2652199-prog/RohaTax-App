# 지침 작성 주의사항 (혼란 방지)

## 📋 개요
이 문서는 새 지침을 추가할 때 혼란을 방지하기 위한 상세한 가이드입니다. 
**핵심 원칙**: 명확하고 구체적인 지침만 작성하세요!

---

## ❌ 피해야 할 지침 패턴 (10가지)

### 패턴 1: 애매한 표현
**❌ 나쁜 예시**:
```
"금액을 더 잘 인식하게 해줘"
"시트 선택을 개선해줘"
"컬럼 매칭을 정확하게"
```

**문제점**:
- 어떤 키워드 추가?
- 임계값 조정?
- 가중치 변경?
- 구체적인 방법 불명확

**✅ 좋은 예시**:
```
"키워드추가: 총배달금액, 순매출액, 정산금액"
"규칙수정: column_matching_threshold 0.8"
"규칙수정: data_density 가중치 0.5로 상향"
```

**이유**: 구체적인 키워드와 값 명시

---

### 패턴 2: 복합 요청
**❌ 나쁜 예시**:
```
"배달업체 처리하고 금액도 개선해줘"
"시트 선택과 컬럼 매칭을 모두 개선"
"키워드 추가하고 임계값도 조정해줘"
```

**문제점**:
- 2가지 이상 작업을 한 번에 요청
- 우선순위 불명확
- 어떤 작업이 먼저 필요한지 모호

**✅ 좋은 예시**:
```
1단계: "키워드추가: 배달업체, 배달대행"
2단계: "키워드추가: 총배달금액, 정산금액"
3단계: "규칙수정: column_matching_threshold 0.8"
```

**이유**: 한 번에 하나씩 명확히 순서대로

---

### 패턴 3: 결과 기반 요청
**❌ 나쁜 예시**:
```
"시트 선택을 더 정확하게"
"컬럼 인식을 개선해줘"
"공급받는자 추출을 더 잘하게"
```

**문제점**:
- 어떤 방법으로?
- 어떤 값을 조정?
- 구체적인 개선 방향 불명확

**✅ 좋은 예시**:
```
"규칙수정: data_density 가중치 0.5로 상향"
"키워드추가: 공급받는자사업자번호, 수취인사업자번호"
"규칙수정: confidence_threshold 0.4로 하향"
```

**이유**: 구체적인 조정 값과 방법 명시

---

### 패턴 4: 업종명만 언급

## 📝 지침 작성 체크리스트

새 지침 작성 시 다음 항목을 확인하세요:

### ✅ 필수 항목
- [ ] 1. 어떤 파일을 수정? (JSON 파일명 명시)
- [ ] 2. 어떤 섹션? (키워드 배열? 가중치? 임계값?)
- [ ] 3. 구체적 값? (키워드 이름, 숫자 값, 정규식)
- [ ] 4. 왜 추가? (어떤 문제 해결 위해?)

### ✅ 명령어 형식
- [ ] 5. 명령어 형식 준수? (키워드추가:, 규칙수정:, 검증규칙:)
- [ ] 6. 콜론(:) 사용? (명령어와 내용 구분)
- [ ] 7. 쉼표(,) 사용? (여러 키워드 구분)

### ✅ 내용 검증
- [ ] 8. 구체적인 키워드? (애매한 표현 없음)
- [ ] 9. 단일 작업? (복합 요청 없음)
- [ ] 10. 객관적 표현? (감정 표현 없음)

## 🚀 명령어 사용 예시

### 기본 명령어 형식
```
키워드추가: [키워드1, 키워드2, ...]
규칙수정: [규칙명] [값]
검증규칙: [필드명] [정규식]
지침추가: [지침 내용]
```

### 실제 사용 예시
```bash
# 키워드 추가
python tools/guideline_command_processor.py "키워드추가: 커피숍, 베이커리, 제과점"

# 규칙 수정
python tools/guideline_command_processor.py "규칙수정: column_matching_threshold 0.8"

# 검증규칙 추가
python tools/guideline_command_processor.py "검증규칙: phone ^010-[0-9]{4}-[0-9]{4}$"

# 지침 추가
python tools/guideline_command_processor.py "지침추가: 공급받는자 전화번호는 필수입니다"
```

## ⚠️ 주의사항

### JSON 파일 수정 시
- ⚠️ 백업 자동 생성됨
- ⚠️ 문법 검증 자동 실행
- ⚠️ 앱 재시작 필요 (JSON 파일은 앱 시작 시 로드)

### 키워드 추가 시
- ⚠️ 중복 키워드 자동 제거
- ⚠️ 쉼표(,)로 구분
- ⚠️ 공백 자동 제거

### 규칙 수정 시
- ⚠️ 숫자 값 자동 변환
- ⚠️ 기존 값 백업
- ⚠️ 변경 전후 값 표시
