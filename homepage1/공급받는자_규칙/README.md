## ⚠️ 중요 사항

### 이 폴더의 역할
- **문서 전용**: 실제 변환 시 읽히지 않음
- **개발자 가이드**: 규칙 이해 및 수정을 위한 참고 자료
- **유지보수**: 체계적인 문서 관리

### 실제 변환 시스템
- **Python 코드**: `core/file_parser.py`, `core/recipient_extractor/` 등
- **설정 파일**: `config/absolute_guidelines_v5.json`, `config/industry_config.json`
- **절대지침**: `절대지침/` 폴더의 MD 파일들

### 새 규칙 추가 시
1. 이 폴더의 문서에서 규칙 설계
2. Python 코드 파일 수정 또는 JSON 설정 파일 수정
3. 테스트 실행 및 검증

### 간단한 지침 추가 시 (권장)
1. `새_지침_추가_완전가이드.md` 참조
2. 명령어 스크립트 사용: `python tools/guideline_command_processor.py "키워드추가: 키워드들"`
3. 앱 재시작: `python app.py`

### JSON 규칙 파일 수정 시
1. `JSON_규칙_파일_완전분석.md` 참조
2. `config/absolute_guidelines_v5.json` 또는 `config/industry_config.json` 수정
3. Python 코드 연결 확인
4. 테스트 실행으로 검증
4. 문서 업데이트
