# 절대지침 시스템 개요

## 📋 목적
세금계산서 변환앱의 모든 템플릿 기입 작업에 대한 절대적이고 불변의 규칙을 정의하고 관리합니다.

## 🏗️ 시스템 구조

### 📁 디렉토리 구조
```
절대지침/
├── 템플릿규칙/           # 템플릿 관련 모든 규칙
├── 공급자정보규칙/       # 공급자 정보 입력 규칙
├── 검증규칙/            # 데이터 검증 및 유효성 규칙
└── README.md            # 이 파일
```

## 🔒 절대 원칙

### 1. 불변성 원칙
- **절대지침은 절대 수정되지 않습니다**
- 변경이 필요한 경우 새로운 버전을 생성합니다
- 모든 변경사항은 버전 관리 시스템에 기록됩니다

### 2. 일관성 원칙
- 모든 템플릿 기입은 동일한 규칙을 따릅니다
- 예외는 허용되지 않습니다
- 모든 사용자는 동일한 규칙을 적용받습니다

### 3. 검증 원칙
- 모든 입력 데이터는 규칙에 따라 검증됩니다
- 검증 실패 시 작업이 중단됩니다
- 검증 로그는 반드시 기록됩니다

## 📝 규칙 카테고리

### 🎯 템플릿 규칙
- 템플릿 구조 정의
- 필드 매핑 규칙
- 데이터 형식 규칙
- 필수/선택 필드 정의

### 👤 공급자 정보 규칙
- 공급자 등록 요건
- 정보 입력 형식
- 필수 정보 항목
- 검증 기준

### ✅ 검증 규칙
- 데이터 유효성 검사
- 형식 검증
- 중복 검사
- 완전성 검사

## 🚀 사용 프로세스

### 1. 규칙 확인
- 작업 전 관련 절대지침을 반드시 확인
- 최신 버전의 규칙을 사용

### 2. 규칙 적용
- 모든 입력에 규칙을 엄격히 적용
- 예외 없이 규칙을 준수

### 3. 검증 수행
- 입력 데이터의 검증 규칙 적용
- 검증 실패 시 작업 중단

### 4. 로그 기록
- 모든 작업 과정을 로그에 기록
- 규칙 적용 결과를 추적

## 📊 버전 관리

### 버전 형식
- `v1.0.0` - 메이저.마이너.패치
- 메이저: 규칙의 근본적 변경
- 마이너: 규칙의 추가 또는 수정
- 패치: 오타 수정 또는 명확화

### 변경 이력
- 모든 변경사항은 변경이력에 기록
- 변경 이유와 영향도 명시
- 승인자와 승인일 기록

## ⚠️ 주의사항

1. **절대지침 위반은 절대 금지됩니다**
2. **규칙 해석이 모호한 경우 상급자에게 문의**
3. **긴급 상황에서도 규칙 우선 적용**
4. **모든 예외는 사전 승인 필요**
