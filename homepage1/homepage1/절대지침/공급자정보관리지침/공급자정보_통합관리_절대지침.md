## 🔄 공급자 정보 처리 프로세스

### **1단계: 유저 정보 조회**

def get_supplier_info(user_id):
    user = get_user_by_id(user_id)

    }

### **2단계: 템플릿 기입**
```python
def write_supplier_info(worksheet, supplier_info, start_row=7, issue_date=None):
    # 세금일자 포맷 변환 (YYYY-MM-DD → YYMMDD)
    tax_date = '251001'  # 기본값
    if issue_date:
        try:
            from datetime import datetime
            date_obj = datetime.fromisoformat(issue_date)
            tax_date = date_obj.strftime('%y%m%d')
        except:
            tax_date = '251001'
    
    # 공급자 정보 기입 (고정값)
    worksheet[f'A{start_row}'] = '01'  # 전자세금계산서 종류 (절대값)
    worksheet[f'B{start_row}'] = tax_date  # 작성일자 (유저 달력 선택)
    worksheet[f'C{start_row}'] = supplier_info['business_number']
    worksheet[f'E{start_row}'] = supplier_info['company_name']
    worksheet[f'F{start_row}'] = supplier_info['representative_name']
    worksheet[f'G{start_row}'] = supplier_info['address']
    worksheet[f'H{start_row}'] = supplier_info['business_type']
    worksheet[f'I{start_row}'] = supplier_info['business_category']
    worksheet[f'J{start_row}'] = supplier_info['email']
    
    # 절대값 기입
    worksheet[f'W{start_row}'] = '30'
    worksheet[f'BG{start_row}'] = '01'
```

## 📋 파일 분할 핵심 조건

### **50개 단위 분할 규칙 (절대 규칙)**
```
50개 = 1개 추출파일
51개부터는 다음 파일로 분할
```

### **분할 계산 예시**
```
- 400개 공급받는자 → 8개 결과물 (400÷50=8)
- 53개 → 2장 추출 (53÷50=2, 나머지 3개)
- 101개 → 3장 추출 (101÷50=2, 나머지 1개)
- 134개 → 3장 추출 (134÷50=2, 나머지 34개)
```

### **카운팅 규칙**
```
1~50번째: 1번째 추출물 (7행=1, 56행=50)
51~100번째: 2번째 추출물 (7행=1, 56행=50)
101~150번째: 3번째 추출물 (7행=1, 56행=50)
```

### **각 파일마다 공급자 정보 기입**
```
파일 1: 7행~56행에 공급자 정보 기입
파일 2: 7행~56행에 공급자 정보 기입
파일 3: 7행~56행에 공급자 정보 기입
```

### **실제 분할 예시 (134개 공급받는자)**
```
파일 1: 1~50번째 (7행~56행)
파일 2: 51~100번째 (7행~56행)
파일 3: 101~134번째 (7행~40행) ← 34개만
```

### **각 파일의 공급자 정보**
```
파일 1: A7=01, B7=YYMMDD, C7~J7=공급자정보, W7=30, BG7=01
파일 2: A7=01, B7=YYMMDD, C7~J7=공급자정보, W7=30, BG7=01
파일 3: A7=01, B7=YYMMDD, C7~J7=공급자정보, W7=30, BG7=01
```
