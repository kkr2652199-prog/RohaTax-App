# 변환시스템 종합 가이드 (Conversion System Comprehensive Guide)

## 📋 개요
VIP 첨부 파일에서 홈택스 템플릿 기입까지의 전체 변환 흐름을 8단계로 요약한 종합 가이드입니다.

---

## 🔄 8단계 변환 흐름 요약

### 1단계: 파일 업로드 검증
**목적**: 파일 형식 및 크기 검증
**코드 위치**: `core/file_parser.py` 라인 327-350
**핵심 로직**: Excel/CSV 형식 확인, 50MB 크기 제한
**결과**: 검증된 파일을 임시 저장소에 저장

### 2단계: 시트 검열 (Sheet Inspection)
**목적**: 최적의 시트 선택
**코드 위치**: `core/file_parser.py` 라인 484-900
**핵심 로직**: Fast-Path 우선 → 점수제 시스템 → 총배달 금액 보너스
**결과**: 최적의 시트 선택 (Fast-Path 또는 점수제)

### 3단계: 헤더 감지 (Header Detection)
**목적**: 데이터 헤더 행 찾기
**코드 위치**: `core/file_parser.py` 라인 163-170
**핵심 로직**: 데이터 밀도 기반 헤더 감지
**결과**: 헤더 행 번호 결정

### 4단계: 7종 컬럼 매칭 (Column Matching)
**목적**: 필수 컬럼과 헤더 매칭
**코드 위치**: `core/file_parser.py` 라인 1162-1236
**핵심 로직**: 부가세 앞칸 규칙 → 5형제 컬럼 매핑
**결과**: 7종 컬럼 매핑 완료

### 5단계: 금지어 필터링 (Forbidden Word Filtering)
**목적**: 잘못된 매칭 차단
**코드 위치**: `core/file_parser.py` 라인 599-858
**핵심 로직**: 7종 금지어 시스템으로 혼동 사례 차단
**결과**: 정확한 컬럼 매칭 보장

### 6단계: 데이터 추출 (Data Extraction)
**목적**: 실제 데이터 추출
**코드 위치**: `core/file_parser.py` 라인 978-1017
**핵심 로직**: 헤더 기반 데이터 추출
**결과**: 가족 정보 리스트 생성

### 7단계: 가족통합 (Family Integration)
**목적**: 중복 데이터 제거 및 통합
**코드 위치**: `core/file_parser.py` 라인 1013-1014
**핵심 로직**: 동일 사업자번호 그룹화
**결과**: 통합된 가족 단위 데이터

### 8단계: 템플릿 생성 (Template Generation)
**목적**: 홈택스 템플릿 생성
**코드 위치**: `core/template_manager.py`
**핵심 로직**: 공급자 → 공급받는자 → 금액 정보 입력
**결과**: 홈택스 템플릿 파일 생성

## 🚀 빠른 참조 (Quick Reference)

### 시트 선택 우선순위
1. **Fast-Path**: "발행용", "정산서", "공유콜" 등 우선 시트
2. **총배달 금액**: 가장 높은 금액의 시트
3. **점수제**: 5형제 컬럼 매칭 점수 (최대 100점)
4. **일반 시트**: 기본 점수 기반 선택

### 7종 컬럼 정의
- **사업자등록번호**: 사업자번호, 등록번호, 거래처번호
- **상호명**: 상호, 업체명, 회사명, 가맹점명
- **주소**: 주소, 사업장주소, 본사주소
- **대표자**: 대표자, 대표명, 사장
- **이메일**: 이메일, 메일주소, 이메일주소
- **공급가액**: 공급가액, 금액, 요금, 가격
- **부가세**: 부가세, VAT, 세금, 세액

### 금지어 시스템 효과
- **5종 기존**: 사업자등록번호, 상호명, 주소, 대표자, 이메일
- **2종 신규**: 공급가액, 부가세 (혼동 사례 100% 해결)
- **혼동 사례**: 11건 → 0건 (-100%)
- **정확도**: 94.2% → 100% (+5.8%)

## 🔧 문제 해결 가이드 (Troubleshooting Guide)

### 시트 선택 문제
- **문제**: 잘못된 시트 선택
- **해결**: Fast-Path 우선순위 확인, 점수제 시스템 점검
- **코드**: `_inspect_all_sheets()` 함수 검토

### 컬럼 매칭 문제
- **문제**: 컬럼 매칭 실패
- **해결**: 7종 금지어 시스템 확인, 키워드 매칭 로직 점검
- **코드**: `_map_columns()` 함수 검토

### 데이터 추출 문제
- **문제**: 데이터 추출 실패
- **해결**: 헤더 감지 로직 확인, 데이터 밀도 계산 점검
- **코드**: `_find_header_row()` 함수 검토

### 템플릿 생성 문제
- **문제**: 템플릿 생성 실패
- **해결**: 공급자/공급받는자 정보 확인, 금액 정보 검증
- **코드**: `TemplateManager` 클래스 검토
