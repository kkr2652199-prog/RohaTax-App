# 변환규칙 폴더 (Conversion Rules Folder)

## 📋 개요
변환 시스템의 모든 규칙과 가이드를 체계적으로 관리하는 폴더입니다. 실제 변환 시스템과 100% 연관 없는 중복 규칙 파일을 정리하고, 공급받는자 규칙 전용 폴더로 재구성되었습니다.

## 🔧 문제 해결 가이드

### 시트 선택 문제
- **문제**: 잘못된 시트 선택
- **해결**: Fast-Path 우선순위 확인, 점수제 시스템 점검
- **코드**: `_inspect_all_sheets()` 함수 검토

### 컬럼 매칭 문제
- **문제**: 컬럼 매칭 실패
- **해결**: 7종 금지어 시스템 확인, 키워드 매칭 로직 점검
- **코드**: `_map_columns()` 함수 검토

### 데이터 추출 문제
- **문제**: 데이터 추출 실패
- **해결**: 헤더 감지 로직 확인, 데이터 밀도 계산 점검
- **코드**: `_find_header_row()` 함수 검토

### 템플릿 생성 문제
- **문제**: 템플릿 생성 실패
- **해결**: 공급자/공급받는자 정보 확인, 금액 정보 검증
- **코드**: `TemplateManager` 클래스 검토

## 🏆 결론

변환규칙 폴더는 변환 시스템의 모든 규칙과 과정을 체계적으로 관리하는 완전한 문서 시스템입니다.

**핵심 특징**:
