# 공급받는자 완전통합지침 (최종본)

## 📋 개요
실제 테스트 100% 성공 결과를 바탕으로 모든 변환 규칙을 다차원적으로 통합한 완전통합지침입니다. 8단계 변환 과정, 규칙 종류별, 실행 순서와 우선순위 중심의 3가지 차원으로 구성되어 있습니다.

---

## ⚠️ 중요: 이 문서의 역할과 실제 변환 시스템

### 이 문서는 참고 가이드입니다

**실제 변환은 Python 코드를 통해 실행됩니다.**

이 문서는 실제 변환 시 읽히지 않으며, 개발자가 규칙을 이해하고 수정하기 위한 참고 문서입니다.

### 3. 컬럼 매칭 우선순위 (실제 코드 기반)

#### 1순위: VAT 앞컬럼 규칙
- **실행 함수**: `_validate_dad_column_before_mom()` (라인 1237-1270)
- **조건**: 부가세(VAT) 컬럼 발견 시
- **검증 로직**: 부가세 앞 컬럼이 공급가액인지 10:1 비율 검증 (9.5:1 ~ 10.5:1 범위 허용)
- **매개변수**: `sheet`, `mom_col: int`, `header_row: int`
- **반환값**: `Optional[int]` (검증된 아빠 컬럼 번호)
- **실제 변수**: `dad_col`, `valid_rows`, `total_rows`, `ratio`
- **템플릿 기입 경로**: 검증 성공 시 공급가액 컬럼 확정 → 템플릿 T열 기입

#### 2순위: 7종 금지어 시스템
- **실행 변수**: `forbidden_keywords_map` (라인 599-858)
- **7종 금지어 카테고리**:
  1. 사업자번호 금지어 (44개)
  2. 업체명 금지어 (38개)
  3. 대표자명 금지어 (31개)
  4. 주소 금지어 (27개)
  5. 전화번호 금지어 (19개)
  6. 이메일 금지어 (15개)
  7. 공급가액 금지어 (12개)
- **매개변수**: `header: str`, `forbidden_list: List[str]`
- **반환값**: `bool` (금지어 감지 시 해당 컬럼 제외)
- **실제 변수**: `forbidden_keywords`, `is_forbidden`
- **템플릿 기입 경로**: 금지어 아닌 컬럼만 매칭 → 템플릿 K,M,N,O,R,T열 기입

#### 3순위: 키워드 매칭
- **실행 함수**: `_map_columns()` 내부 키워드 매칭
- **키워드 우선순위**:
  - 정확 매칭 (예: "사업자등록번호")
  - 부분 매칭 (예: "사업자", "등록번호")
  - 유사 매칭 (예: "사업자번호", "등록번호")
- **매개변수**: `headers: List[str]`, `keywords_list: List[str]`
- **반환값**: `str` 또는 `None` (매칭된 컬럼명)
- **실제 변수**: `business_keywords`, `store_keywords`, `representative_keywords`, `address_keywords`, `email_keywords`
- **템플릿 기입 경로**: 매칭 성공 컬럼 → 템플릿 해당 열 기입
