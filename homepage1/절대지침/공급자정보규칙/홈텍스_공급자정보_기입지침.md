# 🎯 홈텍스 공급자 정보 기입 절대지침

이 문서는 **실제 홈텍스 템플릿**에 공급자 정보를 기입할 때 따라야 할 절대적인 규칙을 제공합니다.

---

## 📋 홈텍스 템플릿 구조 (실제)

### **6행 (헤더)**
```
A6: 전자(세금)계산서 종류
B6: 작성일자  
C6: 공급자 등록번호
D6: 공급자 종사업장번호
E6: 공급자 상호          ← 지능앱 사용
F6: 공급자 성명          ← 지능앱 사용
G6: 공급자 사업장주소     ← 지능앱 사용
H6: 공급자 업태
I6: 공급자 종목
J6: 공급자 이메일        ← 지능앱 사용
```

### **7행부터 (실제 데이터 입력)**
```
A7, A8, A9...: 전자(세금)계산서 종류 (01:일반, 02:영세율)
B7, B8, B9...: 작성일자 (YYYYMMDD 형식)
C7, C8, C9...: 공급자 등록번호 ("-" 없이 입력)
D7, D8, D9...: 공급자 종사업장번호
E7, E8, E9...: 공급자 상호          ← 지능앱 사용
F7, F8, F9...: 공급자 성명          ← 지능앱 사용
G7, G8, G9...: 공급자 사업장주소     ← 지능앱 사용
H7, H8, H9...: 공급자 업태
I7, I8, I9...: 공급자 종목
J7, J8, J9...: 공급자 이메일        ← 지능앱 사용
```

## 🎯 지능앱의 간단한 공급자 정보 규칙

### **사용하는 4개 열만**

| 열 | 필드명 | 실제 위치 | 예시 데이터 | 규칙 |
|----|--------|-----------|-------------|------|
| **E열** | 공급자 상호 | E7, E8, E9... | 바로고인천연수 | 필수 입력, 텍스트 |
| **F열** | 공급자 성명 | F7, F8, F9... | 권강록 | 필수 입력, 텍스트 |
| **G열** | 공급자 사업장주소 | G7, G8, G9... | 인천시 연수구 옥연동308-1 1층2호 | 필수 입력, 텍스트 |
| **J열** | 공급자 이메일 | J7, J8, J9... | kweon4309@naver.co... | 선택 입력, 이메일 형식 |

### **지능앱의 핵심 철학**
- **4개 열만 사용** (E, F, G, J)
- **7행부터 시작** (실제 데이터 입력)
- **간단한 검증** (필수/선택만 구분)
- **즉시 처리** (복잡한 로직 없음)
- **홈텍스 템플릿 구조 그대로 활용**

## 🔍 검증 규칙 (지능앱 방식)

### **1. 공급자 상호 (E열)**

- **형식**: 텍스트
- **예시**: `바로고인천연수`

### **2. 공급자 성명 (F열)**
- **규칙**: 필수 입력
- **형식**: 텍스트
- **예시**: `권강록`

### **3. 공급자 사업장주소 (G열)**

- **형식**: 이메일 형식
- **예시**: `kweon4309@naver.co...`

## 💡 지능앱 vs 우리 시스템 비교

### **지능앱 (간단)**
- 4개 열만 사용 (E, F, G, J)
- 필수/선택 구분만
- 즉시 처리
- 사용자 친화적

### **우리 시스템 (정밀)**
- 모든 열 사용 가능
- 다층 검증 (형식, 논리, 외부)
- 상세한 오류 메시지
- 정확성 우선
